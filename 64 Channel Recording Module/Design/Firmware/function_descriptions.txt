CORE SRC FILES

boot.c
Handles bootloader communication protocol.
processBOOT() responds to bootloader queries with module type, serial number, and firmware version.

emcy.c
Implements CANopen emergency message handling.
emergencyInit() initializes the emergency subsystem.
emergencyStop() halts emergency processing.
EMCY_setError() reports error conditions and transmits emergency messages.
EMCY_errorRecovered() clears error conditions and notifies recovery.
sendEMCY() transmits emergency CAN frames.
proceedEMCY() processes received emergency messages.

lifegrd.c
Manages CANopen heartbeat and node guarding protocols.
getNodeState() retrieves the state of a network node.
ConsumerHearbeatAlarm() handles heartbeat timeout events.
processNODE_GUARD() responds to node guarding requests and processes heartbeat messages.
ProducerHearbeatAlarm() generates periodic heartbeat transmissions.
heartbeatInit() starts heartbeat monitoring and production.
heartbeatStop() terminates heartbeat services.

lss.c
Implements CANopen Layer Setting Services for node configuration.
startLSS() initializes LSS services.
stopLSS() terminates LSS services.
sendSlaveLSSMessage() transmits LSS responses from slave nodes.
sendMasterLSSMessage() transmits LSS commands from master nodes.
sendLSS() routes LSS messages based on master or slave role.
proceedLSS_Master() handles LSS responses received by master.
proceedLSS_Slave() processes LSS commands received by slave.
configNetworkNode() sends LSS configuration commands with callbacks.
getConfigResultNetworkNode() retrieves LSS command results.
LssAlarmMSG() handles LSS message timeouts.
LssAlarmSDELAY() manages baud rate switch delay timing.
LssAlarmFS() controls FastScan protocol timing.

main.c
Contains STM32 initialization and main loop.
SystemClock_Config() configures system clocks.
MX_GPIO_Init() initializes GPIO pins.
MX_GPDMA1_Init() configures DMA channels.
MX_FDCAN1_Init() initializes FDCAN peripheral.
MX_ICACHE_Init() configures instruction cache.
MX_SPI1_Init() sets up SPI1 as master for command transmission.
MX_SPI2_Init() configures SPI2 as slave for MISO A reception.
MX_SPI3_Init() configures SPI3 as slave for MISO B reception.
MX_TIM6_Init() initializes TIM6 for system timing.
main() runs hardware initialization and enters main loop calling updateAppTask().

nmtMaster.c
Provides NMT master functions for controlling slave nodes.
masterSendNMTstateChange() transmits NMT state change commands to slave nodes.
masterSendNMTnodeguard() requests node status from slaves.
masterRequestNodeState() queries slave node state with callback.

nmtSlave.c
Handles NMT slave functionality and state transitions.
processNMTstateChange() receives and executes NMT commands from master.
Implements state transitions between Initialisation, Pre-operational, Operational, and Stopped states.

objacces.c
Manages object dictionary access and error reporting.
accessDictionaryError() logs object dictionary access errors.
_getODentry() retrieves values from object dictionary entries.
_setODentry() writes values to object dictionary entries.
readLocalDict() reads data from local object dictionary with type checking.
writeLocalDict() writes data to local object dictionary with validation.

pdo.c
Implements Process Data Object protocol.
buildPDO() constructs PDO messages from mapped object dictionary entries.
sendPDOrequest() transmits PDO requests.
proceedPDO() processes received PDO messages.
sendPDOevent() triggers event-driven PDO transmission.
PDOInit() initializes PDO subsystem.
PDOStop() halts PDO processing.

sdo.c
Implements Service Data Object protocol for object dictionary access.
_writeNetworkDict() writes to remote node object dictionaries.
_readNetworkDict() reads from remote node object dictionaries.
sendSDO() transmits SDO requests.
proceedSDO() processes SDO responses and requests.
initSDOline() initializes SDO transfer structures.
resetSDOline() resets SDO state machines.
getSDOfreeLine() allocates SDO transfer resources.

st32/can_stm.c
STM32-specific CAN driver implementation.
canSend() transmits CAN messages via FDCAN peripheral.
canReceive() processes received CAN frames.
canChangeBaudRate() modifies CAN bus speed.
canInit() initializes FDCAN hardware.

st32/timer_stm.c
STM32-specific timer implementation for CANopen.
HAL_TIM_PeriodElapsedCallback() handles timer interrupts.
Calls TimeDispatch() for TIM6 to drive CANopen timers.
Calls start_spi_transfers() for TIM2 to trigger sampling.
setTimer() configures timer periods.
getElapsedTime() returns elapsed time since timer start.

states.c
Manages CANopen state machine.
setState() transitions between CANopen states.
getState() retrieves current node state.
switchCommunicationState() enables or disables communication services.

stm32u5xx_hal_msp.c
Hardware abstraction layer peripheral initialization.
HAL_FDCAN_MspInit() configures FDCAN clocks, GPIOs, and interrupts.
HAL_FDCAN_MspDeInit() releases FDCAN resources.
HAL_SPI_MspInit() sets up SPI clocks, GPIOs, DMA channels, and interrupts for SPI1, SPI2, SPI3.
HAL_SPI_MspDeInit() releases SPI resources.
HAL_TIM_Base_MspInit() configures timer clocks and interrupts.
HAL_TIM_Base_MspDeInit() releases timer resources.
HAL_UART_MspInit() initializes UART hardware.
HAL_UART_MspDeInit() releases UART resources.

stm32u5xx_it.c
Interrupt service routines for STM32 peripherals.
NMI_Handler() handles non-maskable interrupts.
HardFault_Handler() processes hard faults.
MemManage_Handler() handles memory management faults.
BusFault_Handler() processes bus faults.
UsageFault_Handler() handles usage faults.
SysTick_Handler() provides system tick timing.
GPDMA1_Channel8_IRQHandler() services UART DMA interrupts.
GPDMA1_Channel9_IRQHandler() services SPI1 TX DMA interrupts.
GPDMA1_Channel10_IRQHandler() services SPI3 RX DMA interrupts.
GPDMA1_Channel11_IRQHandler() services SPI2 RX DMA interrupts.
TIM2_IRQHandler() handles sampling timer interrupts.
TIM6_IRQHandler() handles system timer interrupts.
SPI1_IRQHandler() processes SPI1 interrupts.
SPI2_IRQHandler() processes SPI2 interrupts.
SPI3_IRQHandler() processes SPI3 interrupts.
FDCAN1_IT0_IRQHandler() handles CAN receive interrupts.
USART1_IRQHandler() processes UART interrupts.

sync.c
Implements CANopen SYNC object protocol.
sendSYNC() transmits SYNC messages.
proceedSYNC() processes received SYNC messages.

syscalls.c
System call stubs for newlib C library.
_write() redirects printf to UART.
_read() handles input operations.
_close(), _lseek(), _fstat(), _isatty() provide file operation stubs.

sysmem.c
Dynamic memory allocation implementation.
_sbrk() manages heap allocation.

system_stm32u5xx.c
System initialization for STM32U5 series.
SystemInit() configures FPU, instruction cache, data cache, and vector table.
SystemCoreClockUpdate() updates system clock variables.

timer.c
CANopen timer management.
SetAlarm() schedules timer callbacks.
DelAlarm() cancels scheduled timers.
TimeDispatch() processes expired timers.


CORE APP FILES

module/app.c
Main application coordination.
initAppTask() initializes all application subsystems including CANopen, EEPROM, sampling, and USART.
updateAppTask() main loop function that calls scan_monitor_process().
start_callback() CANopen timer callback.

module/eedata.c
EEPROM data storage management.
eeload() reads configuration from EEPROM.
eesave() writes configuration to EEPROM.
eeclear() erases EEPROM contents.

module/sampling.c
Multi-channel sampling control.
start_spi_transfers() initiates DMA transfers for SPI2 (MISO A), SPI3 (MISO B), and SPI1 (command TX).
scan_monitor_process() checks for completed scans and triggers data processing.
get_sample_rate_hz() returns configured sample rate.
get_active_channel_count() returns number of active channels.
start_sampling_timer() starts TIM2 for periodic sampling.
pause_sampling_timer() pauses TIM2.
stop_data_acquisition() halts all sampling operations.
restart_data_acquisition() resumes sampling.
HAL_SPI_RxCpltCallback() DMA completion callback that sets ready flags when SPI2 or SPI3 finish receiving.
update_sampling_parameters() modifies sample rate and channel configuration from object dictionary updates.
MX_TIM2_Init() configures TIM2 for sample rate generation.
get_spi_debug_info() provides debug information about SPI and DMA states.

module/scan_data_process.c
Processes raw ADC data from Intan amplifiers.
process_scan() combines data from both MISO streams, applies calibration, and prepares for transmission.
format_data_for_uart() converts processed samples to transmission format.
transmit_scan_data() sends formatted data via UART.

module/serial_interface.c
UART communication interface.
start_command_listener() enables USART reception for command processing.
process_uart_command() parses received commands like START and STOP.
HAL_UART_RxCpltCallback() UART receive complete callback.
HAL_UART_TxCpltCallback() UART transmit complete callback.

ObjDict.c
CANopen object dictionary implementation.
Contains definitions for all CANopen objects including device information, configuration parameters, and process data.
Provides callback registration for object dictionary changes.
Defines variables for sample rate (INTAN_SampleRate), active channels (INTAN_ActiveChannels), and data buffers (INTAN_BufferA, INTAN_BufferB).
